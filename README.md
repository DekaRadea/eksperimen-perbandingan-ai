# Eksperimen Perbandingan AI: Claude vs ChatGPT vs Gemini

Eksperimen (5 November 2026) yang membandingkan kode aplikasi web hasil Claude, ChatGPT, dan Gemini. Setiap kode dijalankan di StackBlitz.

## Isi repositori

| Folder / file | Isi |
|---|---|
| `Eksperimen_AI_5Nov2026/` | Kode sumber tiap AI untuk 3 kasus uji (lihat `DAFTAR.txt`) |
| `screenshot-eksperimen/` | Tangkapan layar aplikasi yang berjalan di StackBlitz |
| `dokumen/` | Laporan (.docx) dan presentasi (.pptx) |

## Kasus uji

1. **Kasus1_KopiKita_LandingPage**: landing page statis (HTML/CSS)
2. **Kasus2_Data_Mahasiswa_CRUD**: aplikasi CRUD data mahasiswa (Node.js + SQLite)
3. **Kasus3_Pengumuman_Kampus_Login_Role**: pengumuman kampus dengan login dan role (Node.js + SQLite)

## Menjalankan

Kasus 1: buka `index.html` di browser.

Kasus 2 & 3: masuk ke folder salah satu AI, lalu:

```bash
npm install
npm start
```
